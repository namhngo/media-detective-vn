# Cross-language verification

1. Preserve the original wording where possible before interpreting it.
2. Flag when a translation, subtitle, or abbreviated quote could change the
   claim's subject, certainty, timing, or attribution.
3. Compare the original source and any translation side by side when available.
4. Do not present a translated phrase as an exact quotation unless the source
   supports that precision.
5. Recommend checking the original publication and a trusted translation for
   consequential claims.
