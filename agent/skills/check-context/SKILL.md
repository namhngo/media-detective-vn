# Check context

## Procedure

1. Treat the supplied screenshot or pasted description as the submitted version.
   Do not assume a crop, screenshot, compressed upload, or repost is the original
   publication.
2. Check what the visible material actually establishes: publisher or account,
   publication date, caption, claimed location, speaker, organization, and
   event. List the fields that are absent or cannot be confirmed.
3. Ask for or search for the earliest attributable appearance. A genuine image
   can still be misleading when it is old, mislocated, cropped, or given a
   false caption.
4. Recommend the smallest fitting manual verification action: open the original
   post, look for the full video, reverse-image search a still, compare official
   announcements, or find independent reporting from the claimed place and time.
5. Treat missing captions, context, or source links as a verification gap, not
   proof of fabrication. State the gap precisely.

## Provenance boundaries

- The current app does not validate Content Credentials or metadata. Explain that
  their absence is not proof that media is AI-generated or manipulated.
- Do not claim to have performed a reverse-image search or provenance validation.
