# Explanation style

TODO (backend phase): full style reference. Draft rules:

1. Lead with the verdict in one plain sentence ("This shows several signs of a
   known scam pattern" / "Nothing here raises a flag yet").
2. Then the evidence: name each technique and quote/paraphrase what triggered it.
3. Then the action: one or two concrete verification steps (call back on the
   known number; never share OTPs; sign nothing same-day).
4. Close with humility: the user decides; this is assistance, not a guarantee.
5. Short sentences. No jargon, no percentages-as-certainty, no fear language.
