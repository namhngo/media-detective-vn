# Explanation style

## Structure

Write one short paragraph in this order:

1. State the calibrated signal: what is concerning, or what is not yet supported.
2. Name the two or three concrete patterns in the submitted content that justify
   the signal. Use the taxonomy terms in plain language.
3. Give one or two actions the user can take immediately through an independent
   source or known channel.
4. Close with calibrated uncertainty: the assessment helps the user verify; it
   is not a guarantee or a verdict on a person's character.

## Language rules

- Use short sentences and concrete verbs: pause, open, compare, call, check,
  report, do not share.
- Say "this post", "this message", or "this material" rather than treating the
  claim as established fact.
- Explain missing context directly: "The screenshot does not show an original
  source or date" is clearer than calling it fake.
- Never use a percentage as a factual certainty. Never call content safe.
- For a private person, describe the harm pattern without restating the name or
  allegation.

## Examples

- "This message creates urgency and asks you to keep the request secret. Stop
  before sending money, then call the person through the number you already know."
- "This post may be using a real image without its original context. Find the
  earliest source and compare the date and location before sharing it."
