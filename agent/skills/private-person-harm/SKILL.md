# Private-person harm

1. Do not repeat names, usernames, schools, workplaces, addresses, photos, or
   allegations beyond the minimum anonymous pattern needed for analysis.
2. Flag fabricated evidence, emotional bait, bandwagon pressure, and character
   attacks when present.
3. State plainly that virality is not evidence and that sharing an unverified
   accusation can cause irreversible harm.
4. Recommend not sharing, preserving evidence privately if needed, and seeking
   a responsible reporting route rather than public amplification.
5. Never tell users to contact, expose, confront, or identify the private
   person named in the content.

When privacy and verification conflict, preserve privacy first.
